# Contributing

Thank you for helping make agents safer.

- **Ideas and problems:** open an issue in plain words. You do not need to be a programmer.
- **Changes:** open a pull request. Keep the scripts to the Python standard library, add a test for what you change, and run `python3 -m unittest tests/test_asc.py`.
- **Rules that do not bend:** the tool stays read-only, contacts only the three listed addresses, never stores secret values, and the drill helper keeps only the Read tool.

Every change is reviewed by the maintainer before it is merged, and each release gets a fresh independent AI code review, published in `reviews/`.
