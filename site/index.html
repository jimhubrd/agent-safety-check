1

Have your own AI review the code first

Before you install anything that touches your agent setup, ask Claude or Codex to read it. Paste this into a new chat. It reads the code and tells you, in plain words, whether it does anything beyond what it claims.

Please review the open-source project at https://github.com/jimhubrd/agent-safety-check before I install it. I am not a programmer, so explain in plain words. Check every file and tell me: 1. Every internet address it contacts, and what it sends there. 2. Every file it reads, and every file it writes or deletes. 3. Anything that runs other programs, changes settings, sends messages, or installs anything. 4. Whether anything it does goes beyond what its README says. 5. Your overall verdict: safe to install, or not, and why. Red flags to call out: contacting any address other than registry.npmjs.org, pypi.org or api.osv.dev; reading email, documents or passwords; writing anywhere other than an agent-safety-check folder; hidden or scrambled code. The only official copy is at github.com/jimhubrd/agent-safety-check. Warn me if what I am looking at came from anywhere else.

A good answer names the three public version databases as the only internet addresses, says it writes only to its own folder, and finds nothing that sends or changes settings. If your AI finds something else, do not install it, and please tell me.

2

Install it

Open the Code tab in the Claude desktop app (or Claude Code in a terminal) and paste this:

Install Agent Safety Check version 0.1.0 for me. Download https://github.com/jimhubrd/agent-safety-check/archive/refs/tags/v0.1.0.zip into a temporary folder and unzip it. Copy its kit folder to ~/.claude/skills/agent-safety-check, and copy kit/agents/asc-drill-reader.md to ~/.claude/agents/. Then run: python3 ~/.claude/skills/agent-safety-check/scripts/asc.py selftest (on Windows use python or py instead of python3). Change nothing else, and tell me the result.

Isn't pasting an instruction exactly what this site warns about? Fair question. The difference is who chose it. You picked this instruction, from a page you came to on purpose, after your own AI reviewed the code, and it only installs files that read. A planted instruction arrives hidden inside an email or web page someone else wrote, and asks your agent to do something you never asked for.

3

Run it

In a new Code tab session, type:

Run my agent safety check.

It takes a few minutes. You will be asked to allow it to write a file in its own folder, start its read-only fire drill helper, run its python script, and open the report. Deny anything that mentions sending, sharing or deleting. Your report opens in your browser.

Later: "Open my last safety report". To remove it: "Uninstall Agent Safety Check", which shows you exactly what it will remove before it does.

Why this exists

In September 2025, a fake email connector worked normally for fifteen versions. Version sixteen quietly copied every email it sent to a stranger (Koi Security). In May 2025, a hidden instruction in a public GitHub issue led an agent to leak private project details, including its owner's salary (Invariant Labs). Neither needed anyone to break in. The agent was simply allowed to do it.

Agent Safety Check reports and recommends. It never changes your settings, and it never sends anything about your setup anywhere. Exactly what it touches.
