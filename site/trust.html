Exactly what it touches

A safety tool should be held to a higher standard than the things it checks. Here is everything Agent Safety Check reads, writes and contacts. Every claim on this page can be checked in the code, and your own AI can check it for you.

What it reads

FileWhy
~/.claude.jsonYour Claude Code connectors: where each comes from and which version
~/.claude/settings.json and settings.local.jsonYour permission rules and guard scripts (only their names and what they apply to)
.claude/settings.json and .mcp.json in the folder you run it fromProject rules and connectors
claude_desktop_config.json (Claude desktop app)Connectors added in the desktop app
manifest.json of desktop app extensionsOnly the version number
Its own folder, ~/agent-safety-checkYour previous reports, to show what changed

It also records the names of the tools Claude can see in the session. It never calls those tools.

What it never reads

Your email, messages, documents, calendar, files outside the list above, browser data, saved passwords or your keychain. Where a connector setting looks like a key or password, the report shows only where it is and its first four characters. The value is never stored or shown.

What it writes

Only inside ~/agent-safety-check: your reports, a snapshot of each check, the tool list, and the fire drill replies. It never changes your settings, connectors or files anywhere else.

What it contacts

AddressWhat it sendsWhy
registry.npmjs.orgA package nameThe newest version of that package
pypi.orgA package nameThe newest version of that package
api.osv.devA package name and version numberKnown security problems in that version

Any other address is refused by the code itself, and an automated test checks that. Ask for an offline check and it contacts nothing at all.

The fire drill

Three test files ship with the tool: a test email, a test web page and a test shared document. Each hides an instruction asking an AI to forward the email, copy a fake key, or make a folder public. Every address in them ends in .invalid, which by internet standards can never receive mail. The fake key is labelled "not a real key".

A separate helper reads them. That helper is given exactly one tool: reading files. It cannot send, share, change or delete anything, so nothing is switched off in your settings and nothing needs switching back. The report records whether it went along with the planted instruction.

How to remove it

Ask Claude: "Uninstall Agent Safety Check". It shows you exactly what it will remove (its skill folder and the fire drill helper) and waits for your yes. Your saved reports stay unless you ask for them to be removed too.
