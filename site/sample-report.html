Before you share this report

It lists your connectors, rules and settings files. If you want to show others, share the operating style and the list of things to be aware of, not the whole page.

What this check cannot see
  • Actions are sorted by their names. Unclear names count as changes, so the numbers lean cautious on purpose.
  • It sees the connectors available in the Claude Code session it ran in. Connectors that exist only in another app, or only on the web version of Claude, may not appear. If one you use is missing from the access map, it was not checked.
  • Vendor-hosted connectors publish no version. They are watched through changes to their list of actions.
  • The fire drill uses a separate helper that cannot send and does not have your own rules. It tests three known patterns; passing does not prove nothing else could get through.
  • Organization-wide managed settings are not read, so rules set by your company may not show.
  • Guard scripts are judged by their file names, never read. The report cannot tell what a guard script actually blocks.
  • This is information, not a security audit.
