# Security

If you find a security problem in Agent Safety Check, please report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not open a public issue for security problems.

I will acknowledge reports as soon as I can and credit you in the release notes unless you prefer otherwise.

In scope: anything that makes the tool read, write, contact or change more than the README says, exposes secret values, or lets a drill file cause a real action.
